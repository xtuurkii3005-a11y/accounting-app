# دفتر — نظام الفواتير والضرائب

تطبيق ويب بسيط (بدون خادم أو قواعد بيانات معقدة) لحفظ الفواتير وحساب ضريبة القيمة المضافة تلقائيًا، وترتيبها بالتاريخ والمبلغ والحالة.

كل بياناتك تُحفظ **محليًا على جهازك فقط** داخل المتصفح (لا يوجد إنترنت ولا خادم خارجي، خصوصية كاملة).

---

## 1. تثبيت VS Code (إذا ما عندك)

حمّله من: https://code.visualstudio.com

---

## 2. فك ضغط الملفات

فك ضغط ملف `accounting-app.zip` في أي مجلد تحبه، مثلاً:
`C:\Users\اسمك\Documents\accounting-app`

---

## 3. فتح المشروع في VS Code

1. افتح VS Code
2. من القائمة: **File > Open Folder**
3. اختر مجلد `accounting-app`

---

## 4. تشغيل التطبيق (طريقتان)

### الطريقة الأسهل — بدون أي تثبيت
اذهب لمجلد المشروع في File Explorer، ودبل كلك على ملف `index.html`. بيفتح مباشرة بالمتصفح وشغّال.

### الطريقة الأفضل — عبر VS Code (تحديث تلقائي كل ما تعدّل بالكود)
1. من تبويب الإضافات (Extensions) في VS Code (الأيقونة على اليسار)، ابحث عن **Live Server** وثبّتها (من Ritwick Dey)
2. بعد التثبيت، اضغط زر يمين الماوس على ملف `index.html` واختر **Open with Live Server**
3. بيفتح المتصفح تلقائيًا على نسخة حيّة من التطبيق

---

## 5. طريقة الاستخدام

- زر **"+ فاتورة جديدة"** لإضافة فاتورة: رقمها، تاريخها، اسم العميل، التصنيف، المبلغ قبل الضريبة، ونسبة الضريبة (تلقائيًا 15%، تقدر تغيّرها).
- الجدول يترتب تلقائيًا حسب التاريخ، وتقدر تضغط على أي عمود لترتيبه.
- اضغط على شارة "محصّلة / غير محصّلة" في أي صف لتبديل حالتها مباشرة.
- زر **"تصدير CSV"** يصدّر لك الفواتير الظاهرة حاليًا (بعد أي فلترة أو بحث) كملف إكسل تقدر تفتحه بـ Excel.
- في الشريط الجانبي، تقدر تغيّر نسبة الضريبة الافتراضية لأي فاتورة جديدة.

---

## 6. مسح فاتورة بالصورة (تعبئة تلقائية بالذكاء الاصطناعي)

بدل ما تكتب بيانات كل فاتورة يدويًا، تقدر تصوّرها أو ترفع صورتها ويقرأها Claude ويعبّي لك الحقول تلقائيًا.

**لماذا يطلب مفتاح API؟**
هذا التطبيق يعمل بالكامل على جهازك بدون خادم خاص بنا، فما نقدر نحلل الصور بدون ما تربطه بحسابك الخاص في Anthropic. المفتاح يُحفظ على جهازك فقط ولا يُرسل لأي مكان غير Anthropic مباشرة.

**خطوات الحصول على مفتاح:**
1. افتح https://console.anthropic.com/settings/keys
2. سجّل دخول أو أنشئ حساب، وأنشئ مفتاح API جديد (Create Key)
3. انسخ المفتاح والصقه في خانة "مفتاح Anthropic API" داخل التطبيق (يُحفظ تلقائيًا للمرات القادمة)
4. ملاحظة: يحتاج حسابك رصيد بسيط (Anthropic تعطي رصيد تجريبي مجاني للحسابات الجديدة)، وتكلفة تحليل كل فاتورة صغيرة جدًا (أجزاء من السنت)

**مهم بخصوص الدقة:**
القراءة الآلية للصور ممتازة لكنها ليست معصومة من الخطأ 100%، خصوصًا مع صور غير واضحة أو خط يدوي. لهذا صممت الأداة بحيث:
- تستخرج البيانات وتعرضها لك في نموذج الفاتورة **قبل الحفظ وليس بعده**
- تقدر تراجع كل رقم وتصححه يدويًا إذا لاحظت خطأ
- ما يُحفظ شي بشكل نهائي إلا لما تضغط "حفظ الفاتورة" بنفسك

هذا يضمن دقة البيانات المحاسبية، وهو أهم من السرعة في عمل محاسبي وضريبي.

---

## 7. تعديل التصميم أو الحقول لاحقًا

- الشكل والألوان: ملف `style.css`
- منطق الحسابات والحفظ: ملف `app.js`
- الحقول والنموذج: ملف `index.html`

إذا حبيت تضيف حقول ثانية (مثل الرقم الضريبي للعميل، أو رفع صورة الفاتورة)، قولي وأساعدك تضيفها.

---

## ⚠️ تنبيه مهم

هذا التطبيق أداة تنظيمية شخصية لتتبع الفواتير، وليس بديلاً عن برنامج محاسبة معتمد لدى هيئة الزكاة والضريبة والجمارك (ZATCA) لإصدار فواتير إلكترونية متوافقة مع نظام الفوترة الإلكترونية (Fatoora)، إذا كنت تحتاج فوترة إلكترونية رسمية.
